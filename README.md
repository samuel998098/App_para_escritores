# App_para_escritores
No se vi muchas apps que se venden como paginas o aplicaciones para escribir pero cuestan entonces me piratee una y esta es gratis xd
Sincronizar entre computadoras con Google Drive (estilo git)

Tú siempre trabajas en una copia local; la app copia la historia a una carpeta de Drive de forma segura (nunca se edita el archivo dentro de Drive, así que no se corrompe a medias).

Configuración (una vez en cada computadora):

Instala Google Drive para escritorio e inicia sesión.
Crea una carpeta dentro de «Mi unidad», por ejemplo StoryCampSync.
En la app: Ajustes → Sincronización con Google Drive → Elegir carpeta de Drive… (o menú Drive → Elegir carpeta). Debe ser una carpeta DISTINTA a la de tus historias.
